# Screenshot notes

The six PNGs show all five My Space tabs plus the dark Business Flow theme.

They were rendered from the installed app's real Jinja templates, CSS, and JavaScript UI renderers using synthetic demo profiles, team members, check-ins, and documents. A standalone headless renderer captured the resulting static HTML. No authenticated production browser session or production record payload was used.

Demo identifiers use `DEMO-` prefixes, names are explicitly labelled Demo, and the email address is `demo@example.com`.
